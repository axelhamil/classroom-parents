# extraction rules

Reads deadlines, amendments and what the parent must pay, sign, return or bring out of one Classroom announcement through the `ILanguageModel` port of `packages/llm`. Spec: `classroom-parents-pilot/briefs/ai-spec.md` §4.2 and §6.

1. **A shared result is reached only with the text it was read from.** `extraction_result` keys on the SHA-256 of the announcement as the family's sync read it (plus post id, publication day, time zone, prompt version) and holds no column naming a family; `IExtractionCache` takes the text, never a hash. **Why**: a family can only get the reading of a text it already reads, so one call serves every family of a class without a cross-family leak; `check:extraction-db` proves it.
2. **Only a complete reading is shared.** A result whose second reading failed, and any failure, is returned but never stored. **Why**: a degraded reading cached for 60 days would stop the next sync from fixing it.
3. **The model reads what a parent sees, nothing else.** Before the model: hidden text removed (Unicode tags, runs under a bidi override, zero-width and bidi controls), NFKC, then contacts, links and child names masked; an announcement with no digit, no day or month name and no time word in the 5 school languages is not sent. **Why**: hidden text is an injection channel, and a call that can return nothing is pure cost; the pre-filter recall is gated by the eval (`prefilterMissed` 0) and by `extraction-sharing.test.ts`.
4. **The code decides, the model proposes.** A deadline or a parent action read from a sentence the injection heuristic flags is dropped; any suspicion (heuristic or `injectionSuspected`) sends the rest to review under its category label with no model-written description; an action, an object or a quote absent from the announcement is dropped; an amount is read by regex in the quote, never written by the model. **Why**: an announcement is third-party content (LLM01), the checks are what the parent can trust.
